# 班級行事曆與值日生管理系統 (Classroom Calendar & Duty Roster System)

一個輕量、功能齊全且具備 RWD 響應式設計的班級管理 Web 應用程式。整合了 **自動化值日生輪派機制**、**請假遞補系統**、**班級活動管理**、**值日生統計** 以及 **班級留言板**，能大幅提升班級日常事務管理的效率。

---

## 🌟 核心功能特色

### 1. 智慧值日生自動輪派與遞補
* **固定座號範圍**：支援座號 **1 至 30 號** 的循環輪派。
* **免排班規則自動套用**：
  * **週末免排**：星期六、星期日自動不排班。
  * **星期五免排**：星期五固定不排值日生，輪值座號自動順延至下週一。
  * **整日活動免排**：若當天設有「整日活動」（如校外教學、運動會），系統自動停排值日生，且不消耗輪值座號。
* **即時請假遞補**：當學生請假或沒來時，系統會自動跳過該生並由下一位未請假的學生順延遞補。

### 2. 手動覆蓋與修改值日生
* **彈性微調**：點擊日曆上的任何排班日或點擊「編輯」圖示，即可手動指定當天的值日生（1-30 號）。
* **一鍵還原**：提供「恢復自動排班」功能，可隨時將手動覆蓋的日期還原回系統自動計算的結果。

### 3. 班級活動管理
* **兩種活動類型**：
  * **一般活動**：如「班會」、「小考」，會在日曆上記錄，不影響值日生排班。
  * **整日活動**：如「校慶」、「段考」，系統會自動取消當日值日生排班。
* **日曆整合**：日曆格直接顯示活動標籤，並提供活動管理面板進行新增與刪除。

### 4. 值日生當值統計
* **數據透明化**：即時統計座號 1-30 號學生的「已當次數」與「待當次數」。
* **動態連動**：統計結果會隨請假狀態切換、整日活動新增或手動覆蓋結果即時重新計算。
* **視覺化進度**：以直觀的進度條展示每位學生的當值狀況。

### 5. 班級留言板
* 提供班級內部公告、學生交流或留言互動。
* 自動記錄留言時間與發布者。

### 6. RWD 響應式與現代化介面
* **跨裝置支援**：完美適應 Desktop（電腦）、Tablet（平板）與 Mobile（手機）。
* **雙模式導覽**：電腦端採用側邊欄/雙欄佈局；手機端自動切換為頂部/底部分頁導覽（Tabs）。

## 🛠️ 技術架構

* **HTML5**：語意化結構設計。
* **CSS3 / Tailwind CSS (v3)**：使用 CDN 載入 Utility-First 框架，實現快速靈活的響應式樣式。
* **JavaScript (Vanilla ES6+)**：無須任何打包工具或複雜框架，純原生 JS 實作所有狀態管理與 UI 動態渲染。
* **FontAwesome (v6)**：提供直觀的向量圖示支援。
